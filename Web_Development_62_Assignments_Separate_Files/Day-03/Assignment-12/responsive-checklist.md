# Responsive Conversion Checklist
- [x] Use viewport meta tag.
- [x] Use flexible widths and max-width.
- [x] Use Flexbox/Grid with auto-fit where suitable.
- [x] Add tablet/mobile media queries.
- [x] Use responsive typography with clamp().
- [x] Avoid fixed widths that cause horizontal scrolling.
- [x] Test at 360px, 768px, 1024px and desktop widths.

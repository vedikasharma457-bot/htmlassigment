# Web Development — 62 Assignment Solution Pack

This folder contains starter solutions and practical files organized by Day 1–15.

## Run
- HTML projects: open the relevant `.html` file in a browser, or use VS Code Live Server.
- JavaScript console projects: install Node.js and run `node filename.js`.
- JSON files: open in VS Code or validate with a JSON validator.

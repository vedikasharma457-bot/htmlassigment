# Capstone Proposal: Student Task Planner
## Problem
Students need a simple way to organize assignments, due dates and completion status.
## Users
College students managing coursework and personal study tasks.
## Core Features
- Add, edit and delete tasks.
- Set category and due date.
- Mark tasks complete.
- Filter all, active and completed tasks.
- Save tasks in localStorage.
- Responsive layout and accessible form labels.
## Requirements
- Works in modern desktop and mobile browsers.
- Rejects empty task titles.
- Data remains after page refresh on the same browser.

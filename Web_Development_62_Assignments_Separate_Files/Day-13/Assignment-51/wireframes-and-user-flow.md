# Wireframe and User Flow
## Main Screen
Header: Student Task Planner
Form: Task title | Category | Due date | Add task
Filters: All | Active | Completed
Task list: Checkbox | Title | Category | Due date | Edit | Delete
## User Flow
Open app → Load saved tasks → Enter task details → Submit → Validate → Save → Render updated list.
For an existing task: Select edit → Change title/date/category → Save → Persist → Render.
